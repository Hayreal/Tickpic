# 贴纸复刻最小编辑提示词设计

**日期：** 2026-07-27

## 目标

将贴纸复刻的最终图片编辑提示词精简为最小契约，避免模型因大量细则而重新设计源标签。

## 范围

只修改 `sticker_replica` 的最终编辑提示词。贴纸裂变、贴纸原创、模型协议参数、图片选区和任务数据均保持不变。

## 提示词契约

复刻模式仅保留以下要求：

1. 从输入产品图中识别标签，将其去透视并展平成一张正视的二维矩形标签。
2. 忠实保留源标签的版式、配色、字体风格、字号层级、卖点样式、图形、间距及元素相对位置，不主动美化、放大或重新排版。
3. 只替换用户明确提供的品牌、产品名、容量、卖点或其他附加要求；未被替换的内容和样式沿用源标签。
4. 最终只输出标签本身，不输出瓶身、产品、场景或样机。

移除复刻模式中的标题缩小 20%、安全距离、边框枚举、文案提取兜底和重复最终检查等细则。

## 实现边界

- 为复刻模式单独构建简短提示词，不复用裂变和原创的详细共享段落。
- 保留现有用户字段的转义和品牌注册标识规范化。
- 不修改 OpenAI/Gemini 请求参数。

## 验证

- 单元测试断言复刻提示词包含四项最小要求。
- 单元测试断言复刻提示词不再包含标题缩小、安全距离、详细卖点兜底等旧约束。
- 现有裂变和原创提示词测试继续通过。
