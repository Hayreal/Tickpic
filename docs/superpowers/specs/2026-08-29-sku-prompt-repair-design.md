# SKU 提示词修复设计

日期：2026-08-29

## 目标

修复 SKU 复刻、裂变和原创中的包材形变、批量风格重复、产品名称漂移和参考风格弱化问题。仅调整 OpenAI 图片编辑前的提示词规划和输入数据流，不使用高保真参数、蒙版、新模型或新 UI。

## 输入边界

SKU 源图可能是尺寸图、主 SKU 与其他包材/配件的组合图，或空白包材渲染图。三类输入统一把第一张图视为固定源画布：只允许修改主 SKU 的标签或正面可印刷区域；瓶型、盖子、比例、位置、背景、尺寸标注及其他物体均保持不变。第二张及后续图片只作为标签设计参考，不得提供容器形态。

## 数据流

前端继续按每张输出创建一个任务，以绕开全局图片任务单次最多三张的限制。共享 `outputBatchId`、`variantIndex` 和 `variantTotal` 的 SKU 任务在主进程中只执行一次视觉规划；视觉模型一次返回整批提示词和一份共享文案锁，各任务按序号领取自己的提示词。取消或单独重试某个任务时，可重新规划整批后只使用对应序号。

裂变和原创的最终图片编辑请求同时携带源图和参考图。每条视觉规划提示词外再包一层确定性的英文硬约束，确保视觉模型不能省略源图锁、图片角色、三类输入规则和共享文案锁。

## 模式规则

- 复刻：参考图提供标签文案与视觉设计，用户结构化字段覆盖对应文案。
- 裂变：同批共享品牌、产品名和容量，仅改变版式、配色和图形语言；空白包材缺少身份时，从用户字段优先、否则从参考图提取一次。
- 原创：源图只提供包材与构图，不继承源标签的品牌、文字、颜色、图形或排版；用户字段提供内容，参考图提供主要视觉方向。

## 验证

- 六个裂变任务只触发一次六条提示词的视觉规划，并分别使用正确序号。
- 裂变和原创最终执行时同时收到源图与参考图。
- 最终英文提示词包含源画布硬锁、尺寸图/组合图/空白渲染图规则、参考图角色和共享文案锁。
- 原创提示词明确忽略源标签设计。

## 限制

提示词可以显著降低形变，但不能提供蒙版级像素一致性。本次不增加自动识别或手动选区。
