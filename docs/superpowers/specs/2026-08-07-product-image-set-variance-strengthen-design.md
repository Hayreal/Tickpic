# 套图视觉差异化强化与拼图/宫格结构设计

**日期：** 2026-08-07

## 1. 背景

上版批量为每个变体分配了核心/环境/视觉三个方向，但方向描述偏抽象（“改变子空间”“改变构图重心”），模型无法把这些模糊指令转化为人类可观察的视觉差异。对比图和场景图多张输出之间仍然高度相似。

多场景图的拼图和宫格模式只描述了“组合多个场景”“使用规则网格”，缺少具体的画布分割结构、边框样式、格数与内容分配规则，模型经常返回单张整图而不是分格布局。

## 2. 目标

- 对比图和场景图的每个变体方向改为具体、可观察的视觉差异要求。
- 多场景图的拼图和宫格产生真实的分格布局，切换模式时有可观察的结构变化。
- 不增加 API、UI、请求字段或模型调用。

## 3. 非目标

- 不让模型看到同批其他结果。
- 不增加批次规划模型。
- 不改变对比图内部的 Before/After 一致性、中央 SKU 规则和效果强度。
- 不改变多场景图的禁产品/禁人物硬规则。
- 不改变主图的差异化规则（主图效果已可接受）。

## 4. 变体方向的视觉维度

每个产品套图变体执行提示词时，不再只给抽象方向名称，而是列出该变体必须改变的 3-4 个具体视觉维度。每条维度使用可观察标准，不用主观形容词。

### 4.1 对比图差异维度

每个对比图变体必须明显改变以下维度中的至少三项：

- 目标子区域：场景中的核心问题区域从一处切换到另一处（如从瓷砖表面切换到瓷砖缝隙）。
- 前景物体布局：Before/After 两侧的前景辅助物体位置、密度或类型明显不同。
- 色彩基调：主导色温从暖调到冷调、从明亮到深沉、或从单色到多色。
- 空间深度：画面从浅景深切换到深景深，或背景从平实墙面切换到有层次的前后景。
- 光线方向与强度：主光源从正面切换到侧向、逆光或顶光；阴影区域占比明显改变。
- 问题表现方式：Before 的状态问题从一种形式切换到另一种（如从污渍切换到脏乱，从磨损切换到褪色），After 必须是同一对象在同一区域的对应可信改善。

禁止通过轻微调色、只换标题、只移动产品或只换装饰物达到差异。

### 4.2 多场景图差异维度

每个多场景图变体必须明显改变以下维度中的至少三项：

- 空间类型：从一种空间切换到另一种（如从室内台面切换到室外地面、从明亮厨房切换到昏暗储藏间）。
- 主体对象：核心展示的表面或物体从一种类型切换到另一种（如从瓷砖切换到木质台面、从金属设备切换到布艺表面）。
- 观察距离与角度：从近景切换到中远景、从俯视切换到正视或侧视；主体占画面比例明显不同。
- 光影氛围：从均匀商业光切换到强烈方向光、从白天自然光切换到暖色人工光、或从明亮切换到暗调。
- 背景复杂度：从简单单色背景切换到丰富多层次环境、从空旷切换到密集物体排列。

## 5. 拼图与宫格结构

### 5.1 拼图模式

生成一张图，画布按不规则区域分成指定数量的面板，各面板边界清晰可见，不同面板之间用明显分割线或边框隔开。

- 默认面板数量：4 个。
- 面板形状不允许完全相同，至少需要 2 种不同宽高比。
- 每个面板只展示一个完整、不同的目标场景。
- 不同面板之间不得复用同一场景内容。
- 不得把所有面板填充为相近的色调或内容，每个面板的色调和场景类型必须有可观察的差异。
- 同一批次的不同输出不得复用同一组面板场景组合。

### 5.2 宫格模式

生成一张图，画布用规则网格分割为指定行列的等大小单元格，单元格之间有清晰分隔线。

- 默认网格：2 行 × 2 列，共 4 格。
- 每个单元格展示一个完整、不同的目标场景。
- 不同单元格之间不得复用同一场景内容。
- 网格边框或分隔线必须可见，不得用纯色填充所有单元格导致边界消失。
- 同一批次的不同输出不得复用同一格场景组合。

### 5.3 模式切换

当用户切换拼图或宫格模式时，改动的只是画布分割方式。场景内容差异化规则不受模式影响，仍按变体方向执行。

## 6. 提示词组装

保持现有顺序不变，仅更新变体方向和布局的具体内容：

1. Feature 基础主提示词。
2. Feature 结构化控制项。
3. 结构化业务参数。
4. Feature/场景范围硬规则。
5. 冲突优先级规则。
6. 用户场景词、补充要求和反向要求。
7. Feature 与变体序号对应的具体差异维度 + 拼图/宫格结构指令。
8. 英文可见文字规则。

## 7. 测试

提示词测试覆盖：

- 对比图第 1、2、3 个变体各自携带至少 3 条具体差异维度。
- 多场景图第 1、2 个变体各自携带至少 3 条具体差异维度。
- 拼图模式包含“4 个面板”“不规则”“边界清晰”“不同面板不得复用同一场景”等明确结构指令。
- 宫格模式包含“2行×2列”“等大小”“分隔线可见”“不同单元格不得复用同一场景”。
- 单场景模式不包含拼图或宫格的结构指令。
- 维度描述使用可观察标准（“色彩基调从暖变冷”“景深从浅变深”），无主观形容词。
- 保留完整整提示词的精确匹配测试以供回归。
- 现有对比图中央 SKU、产品展示和效果强度规则不受影响。

## 8. 验收标准

- 默认 3 张对比图各自携带完全不同的 3-4 项视觉差异维度。
- 默认 2 张多场景图携带完全不同的 3-4 项视觉差异维度。
- 拼图模式生成 4 面板不规则分割，宫格模式生成 2×2 规则网格。
- 拼图和宫格明确要求各面板/单元格场景不可重复。
- 单场景模式不受拼图/宫格结构影响。
- 提示词中的差异维度均为可观察标准，不含“更好”“更丰富”“更明显”等主观描述。
- 不新增 API、UI 或请求字段。
- 现有对比图和场景图的非差异化规则保持不变。
