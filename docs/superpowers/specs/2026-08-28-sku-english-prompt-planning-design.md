# SKU 英文提示词规划设计

日期：2026-08-28

## 目标

SKU 复刻、裂变和原创在图片编辑前，先由视觉模型根据 SKU 图、参考图和用户中文输入生成英文执行提示词。提示词保存后，图片模型只按该英文提示词出图，面向 Temu 等海外电商场景。

## 约束

- SKU 原图是固定底图：构图、视角、产品位置、容器外形、盖子/喷头/滴管、比例、材质、透明度、背景和画面内其他物体不得改变。
- 仅标签可印刷区域可编辑；新标签需贴合原承载面、弧度、反光和阴影。
- 适用于瓶、罐、喷雾、滴管和软管等容器，不按参考图改变容器形态。
- 用户可输入中文。视觉模型将产品名、品类、卖点和附加要求转为自然英文；品牌、容量和型号按原值保留。最终执行提示词不得包含中文字符。
- “做成软管”等形态冲突要求只转换成该品类的标签视觉方向，不能改变 SKU 容器。

## 流程

1. 执行器识别三个 SKU 功能并调用已有视觉指令客户端。
2. 视觉模型接收 SKU 图、可选参考图和结构化请求，返回每张输出对应的英文 `prompt` JSON。
3. 执行器校验提示词数量、索引、非空和无中文字符，然后先写入 `image-instruction.txt`。
4. 图片编辑模型逐张使用这些英文提示词生成 SKU 图。

## 模式

- 复刻：参考图提供标签版式、层级、配色和装饰语言；用户给出的品牌、产品名和容量优先。
- 裂变：在源标签基础上改变标签的视觉设计，核心产品身份不变；批量输出须有明显标签差异。
- 原创：从零设计标签；参考图只提供抽象设计方向，不能复制其他品牌或字面文案。

## 边界

不增加 UI 确认页、翻译接口、额外图片生成步骤或新的任务类型。复用已有视觉模型、产物目录和逐张出图循环。

## 验收

- 三个 SKU 模式都会在出图前请求视觉提示词。
- 传给图片编辑模型的 SKU 提示词来自视觉规划且为英文。
- 提示词包含标签编辑和 SKU 锁定约束，并拒绝容器形态修改。
- 中文用户输入的最终提示词被拒绝并使任务报出明确错误，而不是直接传入图片模型。
