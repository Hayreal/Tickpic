# 套图主图版式约束设计

## 范围

仅修改“套图处理 → 主图”（`product_main_image`）。不修改 SKU 爆款主图、独立对比图和多场景图。

## 行为

- 主图标题只能放在顶部区域：左上、右上或顶部横幅；不得放在画面中部。
- 主图标题最多两行，保持水平基线，不倾斜、不透视变形。
- SKU 产品图只能放在左下或右下；保持竖直、标签朝向镜头；不得放在中部或顶部。
- 主图使用 `before_after` 时，对比内容可位于中间；标题和 SKU 仍遵守上述区域约束。
- 多张主图可轮换允许区域，但不能因此退化为固定单一角落模板。

## 实现

视觉规划提示词声明允许区域和标题行数，限制模型输出的 `headline_placement` / `sku_placement`。

最终执行提示词在主图渲染层增加一条兜底硬约束，覆盖视觉规划器可能返回的冲突位置；不新增 UI 控件或用户参数，不改变独立对比图规则。

## 测试

为视觉规划提示词增加位置与两行上限断言；为最终主图执行提示词增加标题顶部、SKU 底部、对比可居中的断言，并确认独立对比图不受影响。
